[h1=概述]

Vox Kbd — 把你那把键盘，复制成无限套。

玩整合包时常会撞上同一堵墙：快捷键不够用。Vox Kbd 把这条墙拆了。它在游戏里额外提供 N 套“虚拟键盘”，每套都跟你手头那把真实键盘一一对应；同一颗物理键，在虚拟键盘 A 里可以绑“切换工具”，在虚拟键盘 B 里又能绑“释放技能”，互不打架。

装上模组，建几套虚拟键盘，到原版按键控制里把功能绑到对应的合成键上，就能用。

不用写脚本，不用改键码表，不用读文档。

## 适用版本

- Minecraft：26.2
- 模组版本：1.0.0
- 加载器：Fabric
- 平台：Windows、Linux、macOS、Android（FCL、ZL2 启动器）

## 安装

把 `voxkbd-mod-1.0.0.jar` 拖进 `mods` 文件夹，启动游戏。第一次启动会在 `config/voxkbd.json` 写出默认配置。

## 怎么打开总控界面

进游戏按 `` ` ``（Esc 下面那格）。改过键的话，去原版按键控制里找“打开 Vox Kbd”改顺手的。

界面中央是一张完整的 17u 键盘图，鼠标键和手柄键也都在；底部一栏是提示和四个按钮。

## 锁定与解锁

每一格代表一个真实按键，规则只有两条：

- **左键**点一格 = 锁住，背景变红。锁住后无论在哪套虚拟键盘里，按它都发原版按键，**永远不会被 Vox Kbd 改写**。
- **右键**点一格 = 解锁，背景回到深灰。解锁后，在虚拟键盘里按它会发出 `VOXKBD_<键盘编号>_<按键>` 合成键，原版按键控制里就能把功能绑上去。

红即锁，灰即没锁。界面什么样，实际游戏里就什么样。

## 切换虚拟键盘

总控界面关掉之后才能切。三种方式：

- 按“**上一个键盘**” → 上一套。
- 按“**下一个键盘**” → 下一套。
- 按住组合键（默认 Ctrl + Alt）再连按数字键 → 直接跳到第几套。`0` 指默认键盘，`1`、`2` 之类是第几套用户键盘。

循环里第一位始终是默认键盘，也就是你真实那把。默认键盘删不掉，也改不了。

## 新建、修改、删除虚拟键盘

总控界面右下角点“**配置**”进入配置页。

顶部三个按钮是循环开关：“原版按键锁跟随：开 / 关”、“键盘切换提示文案：关 / 动作栏 / 标题”、“当前键盘常显示：关 / 动作栏 / tap 栏”。点一下跳到下一个状态，标签跟着变。

中间一排“添加虚拟键盘”“删除虚拟键盘”“修改虚拟键盘”三个按钮——先在下面列表里**点中一行**，“删除”和“修改”才亮。

下方列表就是你的虚拟键盘。第一行默认键盘永远在。其余行点中后高亮，再删再改。

右下角“**返回**”保存改动并回到总控界面。

### 新建

点“添加虚拟键盘”，给这套键盘起名字、写描述（描述可不写）。**点“保存”**才算建好，列表立刻多一行。直接点“完成”或者“撤回”是不会建出来的。

### 修改

列表里选中要改的行，点“修改虚拟键盘”，改完先**点“保存”**写入，再点“完成”退回配置页。直接点“完成”会把你这次未保存的改动也带盘，避免丢东西。

### 删除

列表里选中要删的行，点“删除虚拟键盘”，那一套立刻消失，编号也不会再分给后面。

## 合成键怎么绑功能

Vox Kbd 不往原版按键控制里塞新条目。打开原版设置（选项 → 按键控制），里面还是你熟悉的那一屏功能；列表最上面多出来的三项“上一个键盘”“下一个键盘”“打开 Vox Kbd”是 Vox Kbd 自己的。

把任意功能（不管原版功能还是其它模组的功能）改绑到 `VOXKBD_*` 合成键的方法：选中那个功能 → **按下你想要的物理键**。前提是这个物理键在总控界面里是深灰色——锁着的物理键只能绑成原版按键。

绑好之后，把 Vox Kbd 切到对应那套虚拟键盘，按这个键就触发你绑的功能。

## 锁状态怎么保存

每次锁定、解锁、改任何配置，模组**立刻**写到 `config/voxkbd.json`；启动时也再回写一遍。界面红/灰状态和磁盘上文件始终一致，不会出现“刚才好像没改成功”的情况。

## VOXKBD 永久跟随

只要某项功能在原版按键控制里绑定到 `VOXKBD_*` 合成键，那个合成键对应的物理键就**永远保持解锁**，之后再改什么配置都不会把它锁回去。

## 几个常见情况

- 切到默认键盘时所有键发原版按键，是正常行为。
- 锁着的物理键在虚拟键盘里仍发原版键，这是“锁”的本意：保证原版功能永远可用。
- 第一次启动时 Java 25 会弹 native access 授权，同意即可。
- Android 端走 FCL / ZL2 启动器自带的 JVM，无需额外配置。

## 遇到问题怎么办

崩溃、连不上、卡住之类：先在 GitHub 提交 Issue，https://github.com/AUGUHDAR/VoxKbd 。提交时附上双方日志，路径 `.minecraft/versions/<版本名>/logs/latest.log`。模组不会上传或泄露你的隐私。
