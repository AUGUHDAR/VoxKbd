[h1=概述]

Vox Kbd — 把你那把键盘，复制成无限套。

玩整合包的时候经常会遇到一个问题：快捷键不够用。Vox Kbd 帮你解决这个。它会在游戏里多出几套“虚拟键盘”，每一套都和你的真实键盘一模一样，所以你可以把同一个键，在不同虚拟键盘里绑成不同的事情。装上模组、创建几套虚拟键盘、到原版按键设置里把功能绑到你想要的合成键上，完事。

不用学脚本，不用改文件，不用研究键码表。

## 适用版本

- Minecraft：26.2
- 模组版本：1.0.0
- 加载器：Fabric
- 平台：Windows、Linux、macOS、Android（启动器用 FCL 或 ZL2 的）

## 安装

把 `voxkbd-mod-1.0.0.jar` 丢进 `mods` 文件夹，启动游戏就行。第一次启动会在 `config/voxkbd.json` 生成配置文件。

## 怎么打开总控界面

进入游戏后按 `` ` ``（键盘左上角、Esc 下面那个键）。如果你换过键位，可以去原版按键设置里把“打开 Vox Kbd”改成你顺手的键。

打开后你会看到一张完整的键盘图，鼠标和手柄的按键也都有。屏幕最下面一行是提示和四个按钮。

## 锁定和解锁按键

总控界面里每一格代表一个真实的按键。两件事：

- **左键**点击一格 = 把它**锁住**，变红。锁住后，无论你在哪套虚拟键盘里，按这个键发出来的都是原版按键，**永远不会被 Vox Kbd 拦截**。
- **右键**点击一格 = 把它**解锁**，变回深灰。解锁后，在虚拟键盘里按这个键，发出来的就是合成键 `VOXKBD_<键盘编号>_<按键>`，去原版按键设置里就能把功能绑到它上面。

红就是锁，灰就是没锁，眼睛看到什么样，实际游戏里就是什么样。

## 切换虚拟键盘

总控界面关掉的时候，才能切键盘。三个办法：

- 按“**上一个键盘**” → 跳到上一套。
- 按“**下一个键盘**” → 跳到下一套。
- 按住组合键（默认是 Ctrl + Alt）再连按几个数字键 → 直接跳到第几套。`0` 是默认键盘，`1`、`2` 这些是第几套用户键盘。

第一套循环里的“默认键盘”就是你的真实键盘，永远在，可以切回去，删不掉也改不了。

## 新建、修改、删除虚拟键盘

总控界面右下角“**配置**”按钮点进去。

上面一排三个循环按钮，是各种开关：“原版按键锁跟随：开/关”、“键盘切换提示文案：关/动作栏/标题”、“当前键盘常显示：关/动作栏/tap栏”。每个按钮点一下就切到下一个状态，标签会跟着变。

中间一排“添加虚拟键盘”“删除虚拟键盘”“修改虚拟键盘”三个按钮，先**在下面列表里点中一行**，“删除”“修改”才能用。

下面那个列表就是你的所有虚拟键盘。第一行是默认键盘，删不了也改不了。其它行点中会高亮，然后才能删/改。

右下角“**返回**”保存所有改动，回到总控界面。

### 新建

点“添加虚拟键盘”，给这套键盘起个名字、写个描述（描述可以不写）。**必须点“保存”**，这一套键盘才算建好，列表里立刻能看到。直接点“完成”或者“撤回”是什么都不建的。

### 修改

列表里选中要改的那行，点“修改虚拟键盘”，改完**点“保存”**写入；改完要点“完成”才能退到配置页面。直接点“完成”会把你这次没保存的改动也写进去，避免丢东西。

### 删除

列表里选中要删的那行，点“删除虚拟键盘”，这一套立刻从列表里消失，编号也不会再给后面的用。

## 合成键怎么绑定到功能上

Vox Kbd 不会往原版按键设置里塞一堆新条目。打开原版设置（设置 → 按键控制），你会看到原来那堆功能没有变，但“上一个键盘”“下一个键盘”“打开 Vox Kbd”三项在最上面，这是 Vox Kbd 自己的三个功能。

把任意功能（包括原版功能、别的模组的功能）改绑到 `VOXKBD_*` 合成键的方法：点中那个功能，**按下你想要的物理键**就行。前提是这个物理键没锁（总控界面里是深灰色），锁着的物理键只能绑成它的原版按键。

绑好之后只要在 Vox Kbd 切到对应那套虚拟键盘，按这个键就会触发你绑的功能。

## 锁状态怎么保存

每次你锁定或者解锁一个键、修改任何配置，模组都会**立刻**写到 `config/voxkbd.json` 里。游戏启动时也会再回写一遍。你看到的红/灰状态和磁盘上的文件永远是同步的，不会出现“刚才好像没改成功”之类的情况。

## VOXKBD 永久跟随

只要某项功能在原版按键设置里绑到了一个合成键，那个合成键对应的物理键就**永远保持解锁**，不管你之后改了什么其他配置都不会被锁回去。

## 几个常见情况

- 切到默认键盘时所有键发原版按键是正常的，那本来就是默认层。
- 锁着的物理键在虚拟键盘下还会发原版键，这正是“锁”的意义：让原版功能永远能用到。
- 第一次启动 Java 25 会弹出 native access 授权，点同意即可。
- Android 端通过 FCL / ZL2 启动器使用，启动器自带 JVM，无需额外配置。

## 遇到问题怎么办

- 遇到崩溃、连不上、卡住等问题，先在 GitHub 提交 Issues：https://github.com/AUGUHDAR/VoxKbd
- 提交时附上双方的日志文件，路径：`.minecraft/versions/<版本名>/logs/latest.log`。
- 模组不会上传或暴露你的隐私信息。
