[h1=概述]

Vox Kbd — 把你那把键盘，复制成无限套。

整合包玩家常会撞上一堵墙：快捷键不够用。Vox Kbd 把这堵墙拆了。它在游戏里额外提供 N 套“虚拟键盘”，每套都跟你手头那把真实键盘一一对应；同一颗物理键，在虚拟键盘 A 里绑“切换工具”，在虚拟键盘 B 里又能绑“释放技能”，互不打架。

虚拟键盘 = 一份额外的键位命名空间，不是改键。玩原版 104 键 + 小键盘以外的多套快捷键（例如整合包里有十几条触发型技能），或者想给鼠标 M4–M8、手柄 17 个键位各自挂上不同功能，都可以用它。

## 它是怎么工作的

物理键被 Vox Kbd 捕获后，有两条出路：

- **锁住**（总控 UI 里显示为红色）→ 始终发原版按键。原版 WASD、Shift、F 之类的功能照常用。
- **未锁**（总控 UI 里显示为深灰）→ 当前激活的虚拟键盘若是 A，就发 `VOXKBD_A_<物理键>`；激活 B，就发 `VOXKBD_B_<物理键>`，依此类推。

锁状态是“眼见为实”的：总控 UI 里看到什么颜色，游戏里就是什么行为。

## 怎么用

### 切换虚拟键盘

总控界面关掉的状态下，三种方式：

- 按“**上一个键盘**” → 上一套。
- 按“**下一个键盘**” → 下一套。
- 按住组合键（默认 Ctrl + Alt）再连按数字键 → 直接跳到第几套。`0` 指默认键盘，`1`、`2` … 是第几套用户键盘。

循环第一位始终是默认键盘（也就是你真实那把），可被切到，不可删除、不可修改。

### 锁与解锁

- **左键**点一格 = 锁住，背景变红，按它时永远发原版按键。
- **右键**点一格 = 解锁，背景回到深灰，按它时在当前虚拟键盘下发对应合成键。

### 新建 / 修改 / 删除虚拟键盘

总控界面右下角点“**配置**”进入配置页：

- 顶部三个按钮是循环开关：“原版按键锁跟随：开 / 关”、“键盘切换提示文案：关 / 动作栏 / 标题”、“当前键盘常显示：关 / 动作栏 / tap 栏”，点一下跳到下一个状态。
- 中间一排“添加虚拟键盘”“删除虚拟键盘”“修改虚拟键盘”：先在下方列表里**点中一行**，“删除”和“修改”才亮。
- 下方列表展示你的所有虚拟键盘。第一行是默认键盘，永远在，删不掉也改不了；其余行点中后会高亮，再删再改。

添加：在弹出页填名称（描述可空），**点“保存”**才算建好，列表立刻多一行；直接点“完成”或者“撤回”不会创建。

修改：选行后点“修改虚拟键盘”，改完先**点“保存”**写入，再点“完成”退回。

删除：选行后点“删除虚拟键盘”，该套立刻消失，编号不复用。

### 把功能绑到合成键上

Vox Kbd 不会往原版按键控制里塞新条目。打开原版按键控制（选项 → 按键控制），里面仍是你熟悉的那一屏功能；列表最上面多出三项“上一个键盘”“下一个键盘”“打开 Vox Kbd”，是 Vox Kbd 自己的。

把任意功能（不管原版功能还是其它模组的功能）改绑到 `VOXKBD_*` 合成键的方法：选中那个功能 → **按下你想要的物理键**。前提是这个物理键在总控界面里是深灰色（已锁的物理键只能绑成原版按键）。绑好之后，把 Vox Kbd 切到对应那套虚拟键盘，按这个键就触发你绑的功能。

VOXKBD 永久跟随：一旦某项功能绑到了 `VOXKBD_*` 合成键，那个合成键对应的物理键就**永远保持解锁**，之后再改什么配置都不会被锁回去。

## 一些细节

- 锁状态与全部配置**实时**写入 `config/voxkbd.json`，启动时也会再回写一遍。界面红/灰和磁盘上文件始终一致。
- 锁着的物理键在虚拟键盘下仍发原版键——这是“锁”的本意：保证原版功能永远可用。
- 默认键的“组合键前缀”（默认 Ctrl + Alt）可改成任意组合，组合键按下后再输数字多位（如 `1`+`1` 切第 11 套、`1`+`0` 切第 10 套）也支持。
