[h1=概述]

Vox Kbd — 把物理键盘，复制成无限套。

Vox Kbd 在 Minecraft 26.2 的游戏输入层新增一套系统级合成键 `VOXKBD_<虚拟键盘序号>_<物理键>`（如 `VOXKBD_1_W`），并以此为基础向玩家开放“虚拟键盘”机制，使玩家能够在不改动原版按键系统的前提下，把同一套物理键映射出多套互相独立、可在原版按键设置中分别绑定的可绑定键码。

玩家无需手动修改键码映射文件，无需学习 Lua 脚本或 JSON 配置。把模组放入 mods 文件夹，启动游戏，按 `` ` `` 打开总控 UI，按需创建并命名若干套虚拟键盘，再到原版按键设置中把功能绑定到对应合成键即可。

## 适用版本

- Minecraft：26.2
- 模组版本：1.0.0
- 加载器：Fabric
- 平台：Windows、Linux、macOS、Android（FCL、ZL2）

## 安装

将 `voxkbd-mod-1.0.0.jar` 放入客户端 `mods` 目录后启动游戏，模组即生效。首次启动会在 `config/voxkbd.json` 生成默认配置文件。

## 总控 UI

游戏内按 `` ` ``（默认，可在原版按键设置中修改）打开总控 UI。中心区域是“普通键盘区”与“小键盘区”两个区块盒子，按 17u US-QWERTY 排布；下方依次是“鼠标区”与“手柄区”。底部栏左侧提示“左键锁定，右键解锁”，右侧从左到右为 配置 / 撤销 / 保存 / 完成。

- **左键点击**任一按键格子：锁定该键，背景变红。该键在任何虚拟键盘下都发出原版按键。
- **右键点击**任一按键格子：解锁该键。激活虚拟键盘时该键发 `VOXKBD_<当前虚拟键盘>_<物理键>` 合成键。

## 切换虚拟键盘

总控 UI 关闭状态下使用以下方式切换当前激活的虚拟键盘：

- 按下“上一个键盘”快捷键：切到循环中的上一套键盘。
- 按下“下一个键盘”快捷键：切到循环中的下一套键盘。
- 按住配置中的“组合键前缀”再连续按若干数字键：切到指定序号的虚拟键盘。`0` 代表“默认键盘”，`1`–`N` 代表第 N 套用户创建的虚拟键盘。

默认键盘始终位于切换循环中，可被切到，但不可删除或修改。

## 创建、修改与删除虚拟键盘

打开总控 UI，点击右下角“配置”按钮进入配置页面。配置页面顶部三个循环按钮可在“原版按键锁跟随：开 / 关”、“键盘切换提示文案：关 / 动作栏 / title 全屏标题”、“当前键盘常显示：关 / 动作栏 / tap 栏”之间切换；第二排为“添加虚拟键盘”、“删除虚拟键盘”、“修改虚拟键盘”三个按钮；下方是虚拟键盘列表，列表首行是常驻的“默认键盘 / 你的原生键盘 / 键盘ID 0”，不可删除、不可修改，点击列表中的其它行可将其选中，被选中后删除与修改按钮变为可用；右下角“返回”按钮会保存所有改动并回到总控 UI。

- **添加虚拟键盘**：点击“添加虚拟键盘”，在弹出页面输入名称与描述后，必须点击“保存”按钮以创建该虚拟键盘；保存后该虚拟键盘立即出现在列表中。直接点“完成”或“撤回”不会创建键盘。
- **修改虚拟键盘**：在列表选中后点击“修改虚拟键盘”，在弹出页面修改名称或描述后点击“保存”写入，再点“完成”保存并返回。直接点“完成”会保留未保存的修改并写盘。
- **删除虚拟键盘**：在列表选中后点击“删除虚拟键盘”，该虚拟键盘立即从列表移除，编号不复用。

## 合成键与原版按键设置的关系

模组在原版按键设置中只注册三个条目：“上一个键盘”、“下一个键盘”、“打开 Vox Kbd”。`VOXKBD_*` 合成键是“被绑定的按键”，不会作为条目出现在原版按键设置中。玩家可以把任意功能（包括原版功能或模组功能）改绑到 `VOXKBD_*` 合成键上。

绑定抓键流程：玩家在原版按键设置中点选某项功能并按下一个物理键时，如果该物理键未锁定，则模组会按当前激活的虚拟键盘，把这次按键记录为对应的 `VOXKBD_<当前虚拟键盘>_<物理键>` 合成键。

## 锁与持久化

总控 UI 中显示为红色的按键即代表被锁定，永远发出原版按键；非红色按键代表未锁，激活虚拟键盘时发合成键。规则在原版按键设置中抓键时同样适用。

所有锁状态（包含显式锁定与显式解锁两个集合）以及全部配置项在每次变更时立即写入 `config/voxkbd.json`，启动时也会立即回写一遍，配置文件中不存在抽奖式偏差。

## VOXKBD 永久跟随

一旦某项功能在原版按键设置中绑定到 `VOXKBD_*` 合成键，其对应物理键将永久保持解锁状态，不受其它配置变更影响。

## 配置

主要配置项位于 `config/voxkbd.json`，由模组在变更时实时写入，结构示例：

```
{
  "version": 1,
  "vanillaLockFollow": false,
  "switchCfg": {
    "previousKey": "91",
    "nextKey": "93",
    "openConfigKey": "96",
    "comboPrefix": "CTRL_ALT",
    "comboDigitDebounceMs": 1000,
    "notification": {
      "type": ["ACTION_BAR"],
      "durationSec": 3,
      "alwaysShow": "OFF"
    }
  },
  "keyboards": [
    { "id": 1, "displayName": "keyboard 1", "description": "", "nameKey": "voxkbd.kb.1" }
  ],
  "lock": { "lockedKeys": [], "unlockedKeys": [] }
}
```

玩家无需手动编辑此文件；通过总控 UI 与配置 UI 即可完成全部改动。

## 已知限制

- 仅支持 Minecraft 26.2。
- 桌面端的全局键盘钩子由 JDK Foreign Function & Memory API 直调 `user32`，需要 Java 25 运行时。
- 26.2 的 fabric mappings 不在公共 Maven 仓库，需要本仓库自带的本地 `com.voxcore.mappings` 才能从源码构建。

## 遇到问题怎么办

遇到问题请在 GitHub 提交 Issues，并附上双方日志文件。日志路径：`.minecraft/versions/版本名/logs/latest.log`。上传时请同时描述双方网络环境（家庭宽带 / 校园网 / 手机热点），便于问题定位。
