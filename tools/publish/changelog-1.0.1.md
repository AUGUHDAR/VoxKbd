## 1.0.1

**支持范围从 1 个包扩到 27 个包。**

1.0.0 只有 Minecraft 26.2 的 Fabric 一个包。1.0.1 覆盖三个加载器：

| 加载器 | 版本范围 | 包数 |
| --- | --- | --- |
| Fabric | 1.20 ~ 26.3 | 9 |
| Forge | 1.20 ~ 26.2 | 9 |
| NeoForge | 1.20.1 ~ 26.3 | 9 |

Forge 没有 26.3 的包，因为 Forge 尚未发布 26.3。

**一个包可以装下多个 Minecraft 版本。** 分组依据是版本之间有没有破坏性 API 变更。`1.20.2_1.20.6` 一个包服务 1.20.2 到 1.20.6；`1.21_1.21.5` 一个包服务 1.21 到 1.21.5 全部小版本。按版本号硬切会把同一份代码抄成多份，然后各自长 bug。

### 修复

- **左右修饰键互相顶替。** Windows 钩子只读虚拟键码，左 Ctrl 与右 Ctrl 拿到同一个值。现在读 `LLKHF_EXTENDED` 位区分左右。
- **切换键被自己的钩子吞掉。** 判断"这个键归模组所有"时，拿 Windows 虚拟键码去比一张 GLFW 键码表，两边编号体系不同。按下 `` ` `` 或 `[` `]` 时有几率被截走，切不出键盘。现在统一成 GLFW 键码。

### 关于 26.3

Minecraft 26.3 移除了 GLFW，改用 SDL3。合成键注入改从 `KeyboardHandler#keyPress` 走，窗口焦点改成轮询，键码空间整体换成 SDL scancode。

这条链路目前只做过编译验证，没有在真实 26.3 客户端上跑过。26.3 的包请按 beta 对待，遇到问题带日志反馈。

### 已知限制

- 26.3 的 Android（FCL / ZL2）注入后端没有对应实现，该版本桌面端只走 Windows 钩子。
- 1.20 ~ 1.21.11 的包内置 JNA；26.x 用 JDK 内置的 FFM，不内置。
- 只有简体中文和英文两套翻译。
