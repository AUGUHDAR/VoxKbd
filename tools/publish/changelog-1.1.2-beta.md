# 1.1.2-beta

**两个玩家实测的致命 bug 修了，Forge/NeoForge 在安卓上第一次真正可用。**

## 修复

- **ZL2 / FCL 上切换键盘后键值不变。** 这两个启动器在安卓进程里跑的是完整桌面版 JVM（OpenJDK），不是 Dalvik，模组靠虚拟机名字判断平台，判断落空后整个翻译管线没有启动。现在按启动命令行特征加了一套兜底判定（`-Dos.version=Android-*`、`pojav.path.*`、`glfwstub.*`、`/system/build.prop`），桌面 Linux 不可能同时命中。
- **Forge 1.20.1 加载时弹"未能加载有效的 ResourcePackInfo"。** Forge 1.20.1 要求模组 jar 里有 pack.mcmeta，1.0.1 全部 27 个包都没有。已补。
- **"始终显示"悬浮标在 1.20 ~ 1.21.11 上从未显示过。** 悬浮标的 mixin 参数和各版本的 `Gui.render` 真实签名对不上（1.20 系缺 `float partialTick`，1.21 系缺 `DeltaTracker`），编译期不报错、运行期静默失效。本轮逐版本对照官方映射文件全部修正。
- **Forge / NeoForge 没有安卓注入桥。** 1.0.1 的桥类只在 Fabric 包里，Forge 和 NeoForge 玩家在 FCL / ZL2 上翻译管线是死的。已按版本族补齐 17 个包。

## 新增

- **更新检测。** 启动后查一次 GitHub Releases（每实例每天最多一次，失败静默），进世界后在聊天栏提示新版本号和下载地址。

## 支持范围

Forge 补上了 26.3，现在三个加载器合共覆盖 1.20 ~ 26.3，共 28 个包。

| 加载器 | 版本范围 | 包数 |
| --- | --- | --- |
| Fabric | 1.20 ~ 26.3 | 9 |
| Forge | 1.20 ~ 26.3 | 10 |
| NeoForge | 1.20.1 ~ 26.3 | 9 |

## 关于 26.3 和安卓

Minecraft 26.3 移除了 GLFW 改用 SDL3，安卓注入桥重写为直接拦截 `KeyboardHandler#keyPress`，不再依赖启动器的注入接口；焦点检测从回调改成轮询。1.20 ~ 26.2 的包沿用原来的回调包装方案，1.21.9+ 已核实内部调用点仍然存在。

这些链路本轮做过了逐版本签名核对（官方映射文件级），但安卓真机和 26.3 桌面端仍然没有跑过实机。**所以这版整体标 beta**：能玩，遇到问题带 `latest_game.log` 反馈。

## 已知限制

- 1.20 ~ 1.21.11 的包内置 JNA；26.x 用 JDK 内置的 FFM，不内置。
- 1.20 系的安卓桥读默认键码表，改过键码表配置的玩家在安卓上会错位（1.21 起读配置）。
- 只有简体中文和英文两套翻译。
